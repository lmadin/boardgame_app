# 🎲 MT 보드게임장 실시간 웹앱

2일차 레크레이션(보드게임장 + 미니게임장, 개인전, 참가자 약 23명 / 운영진 8명)을 위한 실시간 배팅·순위 웹앱입니다.
칩을 실물로 주고받을 필요 없이, 참가자·부스 운영진(MC)·전광판·관리자가 각자 화면에서 실시간으로 연동됩니다.

## 화면 구성

| 화면 | 경로 | 사용자 |
|---|---|---|
| 참가자 | `/` | 참가자 23명 — 본인 폰으로 접속 |
| 부스 운영 | `/booth.html` | MC 8명 — 담당 부스 PIN으로 로그인 |
| 관리자 | `/admin.html` | 총괄 운영진 — 관리자 PIN(`1234`, 변경 가능)으로 로그인 |
| 전광판 | `/leaderboard.html` | 큰 화면에 띄워두는 실시간 순위판 (로그인 불필요) |

## 확정된 게임 라인업 (부스 설명 팻말 반영)

앱을 처음 켜면 아래 9개 부스가 자동으로 만들어집니다. PIN은 무작위로 배정되며 `/admin.html` → 부스 탭에서 확인/수정할 수 있습니다.

| 부스 | 게임 | 담당 | 기본 배당 | 비고 |
|---|---|---|---|---|
| A | 할리갈리 (보드) | 최시원 | 등수차마다 +0.5배, 최대 2.5배 | 승리 시 MC가 배당을 직접 입력 |
| B | 다빈치코드 (보드) | 박민강 | 등수차마다 +0.5배, 최대 2.5배 | 승리 시 MC가 배당을 직접 입력 |
| C | 세트 (보드) | 최가은 | 등수차마다 +0.5배, 최대 2.5배 | 승리 시 MC가 배당을 직접 입력 |
| D | 펭귄 얼음깨기 (보드) | 지민 | 1.5배 고정 | 참가자 1~2명 |
| E | 랜덤 술게임 데스매치 (미니) | 임규민 | 1.5배 고정 | 참가자 3명, 2분 타임어택 |
| F | 알까기 (미니) | 정다율 | 2배 고정 | 1:1 전용 |
| G | 인디언 홀덤 (미니) | 최은혁 | 등수차마다 +0.5배, 최대 2.5배 | "다이" 버튼 = 베팅칩 절반만 소멸 |
| H | 라이어·1부 (미니) | 임영진 | 라이어 2배 / 나머지 1.5배 | 참가자별로 배당을 다르게 입력 |
| I | 끝말잇기·2부 (미니) | 임영진 (H와 동일 MC) | 1.5배 고정 | 2부에만 진행 — 1부엔 배팅받지 마세요 |

H/I는 같은 임영진 MC가 1부/2부에 각각 다른 게임으로 운영하는 부스라, 두 부스를 동시에 열어두고 "1부엔 끝말잇기 부스 배팅 안 받는다"는 걸 현장에서 공지하는 방식으로 운영하기로 했습니다.

## 확정 타임라인 (총 97분)

| 시간 | 내용 |
|---|---|
| 0~8분 | 오프닝 + 룰 설명 + 시드칩 지급 |
| 8~40분 | 1부: 자유 순회 배팅 (32분) |
| 40~50분 | 중간 순위 발표(TOP5) + 조커 이벤트(패자부활전, 10분) |
| 50~82분 | 2부: 자유 순회 배팅 (32분) |
| 82~92분 | 마켓 경매 (10분) |
| 92~97분 | 최종 정산 + 시상식 (5분) |

앱이 시간에 따라 자동으로 화면을 바꿔주지는 않습니다 — 배팅은 90분 넘게 항상 열려있고, "중간 순위 공개"나 "시상식 모드"는 그 타이밍에 맞춰 진행자가 직접 화면을 전환해주는 방식입니다.

## 구현된 기능

- **참가자 등록**: 이름 입력 → 시작칩(기본 100) 자동 지급, 실시간 잔여칩/순위 확인. 동명이인은 자동으로 `이름(2)` 형태로 구분됩니다.
- **부스 배팅**: 참가자 선택(1:1 또는 1:3) → 배팅칩 입력 → **승 / 다이 / 패** 중 선택. "승"을 누르면 그 판에 적용할 배당을 MC가 직접 입력합니다(부스 화면에 표시되는 룰 메모를 참고). "다이(폴드)"는 베팅칩 절반만 소멸(인디언 홀덤용). 최소 배팅칩 미만, 잔여칩 초과(올인 초과) 배팅은 자동 차단됩니다.
- **실시간 순위**: 전체 참가자 자동 정렬, 1~3위 메달 표시, 전광판 화면에 큰 화면용 시상대 UI 포함. 화면 우측 하단 "시상식 모드" 버튼으로 최종 1위/2위/3~5위 그룹 연출 전환 가능.
- **마켓 경매**: 관리자 화면에서 품목/낙찰가/낙찰자 입력 → 즉시 칩 차감.
- **핀볼 도박전**: 참가자는 무료공 1개 자동 보유, 추가 공은 개당 10칩(설정 가능)으로 무제한 구매. 관리자가 최종 1·2·3등 공을 지정하면 250%/180%/120%(설정 가능) 환급, 나머지는 자동 소멸 처리됩니다.
- **현상금 부스**: 부스 운영진이 5연승(설정 가능)하면 자동으로 "🔥 현상금 부스"가 되어, 그 상태에서 이기는 참가자는 배당에 추가 배수(기본 +1배) 또는 고정 보너스칩을 자동으로 더 받습니다(MC가 입력한 배당 위에 서버가 자동으로 얹어줌). 참가자가 한 번이라도 이기면 즉시 초기화됩니다.
- **조커 이벤트**: 관리자 화면 "조커 이벤트" 탭에서 참가자를 검색해 물병세우기 성공(+10칩) 또는 팔씨름 승리(+15칩)를 지급합니다. 잔여칩이 기준(기본 10칩) 이하인지, 이미 참여했는지 화면에 경고로 표시되지만 최종 판단은 진행자가 합니다.
- **관리자 도구**: 부스 이름/유형/기본 배당/룰 메모/PIN 관리, 참가자 수동 칩 조정(오류 정정용), 순위 CSV 내보내기, 각종 배당/최소배팅/현상금/조커 이벤트 기준 설정, 전체 데이터 초기화(리허설 후 실사용 전 필수).

## 로컬에서 실행하기 (리허설용)

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속. 데이터는 `data.sqlite` 파일에 저장됩니다.

## 행사 당일 배포 방법 — 두 가지 옵션

실시간 배팅/순위 반영을 위해 서버가 계속 켜져 있어야 합니다. 아래 두 방식 중 상황에 맞게 선택하세요.

### 옵션 A. 노트북을 서버로 사용 (추천 — 가장 안전하고 간단함)

행사장 와이파이(또는 노트북 핫스팟)에 모든 참가자/운영진 기기를 연결하고, 노트북 1대에서 서버를 실행합니다.

1. 이 프로젝트 폴더를 노트북에 옮기고 `npm install` 1회 실행 (인터넷 필요, 행사 전에 미리 해두세요)
2. `npm start`로 서버 실행
3. 같은 와이파이에 접속된 상태에서 노트북의 로컬 IP 확인
   - Mac/Linux: `ifconfig | grep inet` (또는 `ipconfig getifaddr en0`)
   - Windows: `ipconfig`에서 IPv4 주소 확인
4. 참가자들에게 `http://<노트북IP>:3000` 접속 링크(또는 QR코드)를 공유
5. 부스 운영진은 `http://<노트북IP>:3000/booth.html`, 관리자는 `/admin.html`, 전광판은 `/leaderboard.html`

장점: 인터넷 연결이 끊겨도(같은 와이파이 안에서는) 문제없이 동작하고, 서버가 중간에 재시작될 위험이 없어 90분 내내 데이터가 안전하게 유지됩니다. 노트북 전원 관리(절전모드 방지)만 신경 써주세요.

### 옵션 B. 클라우드에 배포해서 외부 URL로 접속 (Render 기준, 유료 Starter + 디스크)

인터넷 URL로 어디서든(와이파이든 데이터망이든) 접속하게 하려면 [Render](https://render.com)의 Web Service를 추천합니다. 무료 플랜은 재시작 시 데이터가 사라지는 "임시 디스크"라서, **반드시 유료 Starter 플랜($7/월) + Persistent Disk(디스크 1GB, $0.25/월)를 함께 써야** 90분 동안 데이터가 안전하게 유지됩니다.

이 프로젝트에는 `render.yaml`(Render 설정 파일)이 이미 포함돼 있어서, GitHub에 올리고 Render에서 "Blueprint"로 연결하면 이름/디스크/환경변수가 자동으로 세팅됩니다.

1. 이 프로젝트를 GitHub 저장소에 올립니다 (git 몰라도 GitHub 웹사이트에서 파일 드래그앤드롭으로 가능).
2. Render 대시보드 → **New +** → **Blueprint** → 방금 만든 저장소 선택 → Apply
   (Blueprint를 못 찾으면 New + → Web Service로 수동 연결 후, Instance Type을 **Starter**로, Advanced에서 **Add Disk**로 Mount Path `/var/data`, 크기 1GB 추가하고, 환경변수 `DATA_DIR=/var/data` 추가)
3. 결제 수단 등록 (Starter 플랜은 카드 등록이 필요합니다)
4. 배포 완료 후 발급되는 `https://xxxx.onrender.com` 링크를 참가자들에게 공유

**요금 관련 좋은 소식**: Render는 초 단위로 과금됩니다. 즉 한 달 요금을 통째로 낼 필요 없이, 배포한 시점부터 서비스를 지우는 시점까지 실제로 켜져 있던 시간만큼만 청구돼요. 행사 며칠 전에 올려서 리허설하고, 행사 끝난 뒤 며칠 안에 Render 대시보드에서 서비스를 **삭제(Delete)**하면 실제 청구액은 $7보다 훨씬 적습니다 (하루 이용 기준 대략 30센트 내외 + 디스크 비용).

**행사 하나만 안전하게 치르는 게 목적이라면 옵션 A(노트북 서버)도 여전히 무료 대안으로 유효하지만, 지예님처럼 와이파이 안정성이 걱정되는 경우엔 옵션 B(유료 Render)가 더 안전합니다.**

## 사전 준비 체크리스트

1. `npm install`을 미리 실행해 인터넷 없이도 뜨는지 확인
2. `/admin.html`에서 관리자 PIN(`1234`)으로 로그인 → "부스" 탭에서 9개 부스(A~I)의 PIN을 확인해 각 담당 MC에게 개별 전달 (이름/배당/룰 메모는 위 표 그대로 미리 세팅되어 있어 수정할 필요 없음)
3. "설정" 탭에서 이벤트 이름, 최소 배팅칩, 현상금 기준, 핀볼 공 가격, 조커 이벤트 기준 등을 원하는 값으로 조정
4. 리허설을 충분히 진행한 뒤, **반드시 "설정" 탭 하단 "전체 초기화"를 눌러 테스트 데이터를 지우고 실제 행사를 시작하세요.**
5. 전광판용 PC/TV에서 `/leaderboard.html`을 미리 띄워두고, 85분 시점에 우측 하단 "시상식 모드" 버튼으로 전환

## 데이터/보안 관련 참고

- 이 앱은 통제된 1회성 행사를 전제로 최소한의 인증(부스 PIN, 관리자 PIN)만 사용합니다. 외부에 공개된 URL로 배포할 경우 PIN이 새어나가지 않도록 주의해주세요.
- 참가자 등록/기기 인증은 브라우저 로컬 저장소(localStorage)에 기기별로 저장됩니다. 참가자가 다른 기기로 접속하면 새로 등록해야 합니다.
